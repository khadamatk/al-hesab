# USER STORIES - عَ الحساب

## Epic 1 - المساحات المالية

### US-1.1 - فصل الشخصي والفريلانس والشركة

**كمستخدم، أريد** مساحات مالية منفصلة، **حتى** لا تختلط أرصدتي وتقاريري الشخصية بأعمال الفريلانس أو الشركة.

- [ ] إنشاء/إعادة تسمية/أرشفة مساحة.
- [ ] أنواع: شخصي، فريلانس، شركة، أخرى.
- [ ] الحسابات والفئات والحركات والميزانيات والديون تتبع مساحة واحدة.
- [ ] آخر مساحة مستخدمة يمكن تذكرها محليًا، مع مبدل واضح.

## Epic 2 - الحسابات والأرصدة

### US-2.1 - إدارة الحسابات

**كمستخدم، أريد** إضافة كاش وبنك ومحفظة وPayPal، **حتى** أعرف مكان كل مبلغ.

- [ ] اسم الحساب ونوعه ومزوده ووصف آمن اختياري.
- [ ] الحساب المستخدم تاريخيًا يُؤرشف ولا يُحذف.
- [ ] يمكن منع الرصيد السالب افتراضيًا لكل حساب.

### US-2.2 - جيوب العملات والرصد الافتتاحي

**كمستخدم، أريد** أكثر من عملة داخل الحساب عند الحاجة، **حتى** يمثل PayPal وغيره الواقع.

- [ ] كل حساب يملك pocket واحدًا أو أكثر، واحدًا لكل عملة.
- [ ] PayPal يمكن أن يملك USD وEUR وغيرهما كأرصدة منفصلة.
- [ ] الرصيد الافتتاحي حركة موثقة وليس حقلًا قابلًا للتعديل الصامت.
- [ ] الرصيد الحالي مجموع الحركات المنشورة.

## Epic 3 - الدخل والمصروف والفئات

### US-3.1 - تسجيل دخل

**كمستخدم، أريد** تسجيل دخل في حساب محدد، **حتى** أعرف مصدر الأموال ورصيد الحساب الصحيح.

- [ ] مبلغ موجب، pocket، فئة دخل، تاريخ، وطرف/قناة/ملاحظة اختياريون.
- [ ] يظهر في تقارير الدخل والتدفق ولا يظهر كمصروف.

### US-3.2 - تسجيل مصروف

**كمستخدم، أريد** تسجيل مصروف من حساب محدد بسرعة، **حتى** ينخفض الرصيد وتُحدّث الميزانية.

- [ ] مبلغ موجب في الواجهة يُحفظ كقيد سالب.
- [ ] pocket وفئة مصروف وتاريخ إلزاميون.
- [ ] منع الرصيد السالب إلا لو الحساب يسمح به.
- [ ] تعديل/إلغاء الحركة يعيد الحساب بأمان.

### US-3.3 - إدارة الفئات

- [ ] فئات income وexpense منفصلة لكل مساحة.
- [ ] منع الاسم المكرر داخل النوع والمساحة.
- [ ] إعادة ربط الحركات قبل أرشفة فئة مستخدمة.

## Epic 4 - التحويلات وقنوات الدفع

### US-4.1 - تحويل بين حساباتي

**كمستخدم، أريد** نقل المال بين حساباتي، **حتى** يتغير مكانه من غير تضخيم الدخل أو المصروف.

- [ ] تحويل نفس العملة يخصم ويضيف المبلغ نفسه atomically.
- [ ] مثال ATM: البنك ينخفض والكاش يزيد.
- [ ] الرسوم مصروف منفصل مرتبط بالتحويل.
- [ ] التحويل داخل مساحة واحدة فقط؛ النقل بين المساحات حركتان مرتبطتان بتصنيف واضح.

### US-4.2 - تحويل عابر للعملات

**كمستخدم PayPal، أريد** تسجيل ما خُصم بالدولار وما وصل بالجنيه أو الدرهم، **حتى** يعكس التطبيق القيم الفعلية.

- [ ] مبلغ وعملة المصدر إلزاميان.
- [ ] مبلغ وعملة الوجهة إلزاميان.
- [ ] لا يجلب التطبيق سعر صرف ولا يخمن المبلغ.
- [ ] يعرض effective rate مشتقًا للمراجعة فقط.
- [ ] الرسوم تسجل بعملتها الفعلية.

### US-4.3 - استخدام InstaPay كقناة

- [ ] ربط InstaPay بحساب بنكي أو أكثر.
- [ ] اختيار البنك المستخدم عند تسجيل الحركة.
- [ ] لا يظهر رصيد مستقل باسم InstaPay.
- [ ] يمكن فلترة الحركات حسب قناة InstaPay.

### US-4.4 - إرسال لطرف خارجي

- [ ] التحويل لشخص/مورد يسجل مصروفًا أو دفعة دين حسب الغرض.
- [ ] لا يُنشأ حساب مملوك للمستخدم باسم المستلم.
- [ ] يمكن حفظ العملة والمبلغ الذي استلمه الطرف عند اختلافهما عن المصدر.
- [ ] لا يتطلب حفظ مبلغ التسوية إنشاء destination account للطرف الخارجي.

## Epic 5 - الديون والمستحقات

### US-5.1 - دين عليّ

**كمستخدم، أريد** تسجيل دين عليّ وسداداته، **حتى** أعرف المتبقي والاستحقاق.

- [ ] طرف وعملة وأصل مبلغ وتاريخ واستحقاق اختياري.
- [ ] استلام قرض يمكن أن يزيد حسابًا من غير اعتباره دخلًا.
- [ ] دفعات جزئية من حساب محدد.
- [ ] منع دفع أكثر من المتبقي.
- [ ] سداد أصل القرض لا يظهر كمصروف؛ الفائدة أو الرسوم فقط مصروف منفصل.

### US-5.2 - مستحق لي

**كفريلانسر أو صاحب شركة، أريد** تسجيل مبالغ مستحقة عند العملاء وتحصيلها، **حتى** لا أخلط الفاتورة بالمال المقبوض.

- [ ] إنشاء receivable لا يزيد رصيد الحساب.
- [ ] التحصيل فقط يزيد الرصيد.
- [ ] دفعات جزئية وحالة open/partial/settled.
- [ ] تقرير حسب العميل والاستحقاق والمتبقي.
- [ ] تحصيل invoice يظهر دخلًا cash-basis، بينما استرداد مال مُقرض لا يظهر دخلًا.

## Epic 6 - الميزانيات والتنبيهات

### US-6.1 - ميزانية شهرية

- [ ] حد عام لكل مساحة/عملة أو حد لفئة مصروف.
- [ ] income والتحويلات والديون لا تدخل في المصروف المحتسب.
- [ ] نسخ أحدث حدود إلى الشهر الجديد بدون تغيير التاريخ.

### US-6.2 - تنبيهات

- [ ] تنبيه افتراضي عند 80% وعند 100%+.
- [ ] كل مستوى مرة واحدة لكل ميزانية شهرية.
- [ ] إعادة الحساب بعد تعديل/إلغاء المصروف.

## Epic 7 - التقارير

### US-7.1 - لوحة الأرصدة

- [ ] رصيد كل account pocket منفصل.
- [ ] إجمالي حسب العملة داخل المساحة بدون جمع العملات المختلفة.
- [ ] فصل المساحات افتراضيًا.

### US-7.2 - الدخل والمصروف والتدفق

- [ ] تقارير حسب الفترة والمساحة والعملة والحساب والفئة والطرف.
- [ ] التحويل الداخلي لا يظهر كدخل أو مصروف.
- [ ] الرسوم تظهر كمصروف.

### US-7.3 - الديون والمستحقات

- [ ] إجمالي ومتَبقي وقادم الاستحقاق حسب العملة والطرف.
- [ ] لا تجمع العملات في رقم واحد.

## Epic 8 - التشغيل المحلي وسلامة البيانات

### US-8.1 - Offline ومراجعة الحركات

- [ ] كل الوظائف تعمل بلا إنترنت.
- [ ] كل تغير في الرصيد له حركة ووقت وسبب.
- [ ] لا تستخدم `double` ماليًا.
- [ ] العمليات المركبة transactions ذرية مع foreign keys.

- أسعار صرف حية أو تحويل آلي.
- AI insights.
- مزامنة وحسابات مستخدمين.
- محاسبة ضريبية وفواتير قانونية كاملة.
