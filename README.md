# عَ الحساب | Al Hesab

تطبيق Flutter عربي مفتوح المصدر لإدارة الأموال محليًا: حسابات متعددة العملات، دخل ومصروف، تحويلات، ديون ومستحقات، ميزانيات وتقارير. يعمل بأسلوب offline-first ولا يحتاج حساب مستخدم أو خادم خلفي.

## المميزات

- مساحات منفصلة للشخصي والفريلانس والشركة.
- حسابات وجيوب عملات مستقلة، وتحويلات بين العملات بالمبلغ الفعلي.
- تقسيم المصروف الواحد على عدة فئات.
- ديون ومستحقات ودفعات جزئية.
- ميزانيات وتقارير بفترات مخصصة.
- قفل اختياري ببصمة أو رمز الجهاز.
- نسخ احتياطي واستعادة محليان.
- واجهة عربية RTL ووضع فاتح وداكن.

## الخصوصية

البيانات المالية محفوظة داخل مساحة التطبيق على الجهاز. لا توجد إعلانات أو تحليلات أو مزامنة سحابية في الإصدار الحالي. راجع [سياسة الخصوصية](md/PRIVACY_POLICY.md) و[نموذج الأمان](md/SECURITY.md).

## التشغيل محليًا

المتطلبات: Flutter stable وAndroid SDK، أو Xcode لبناء iOS.

```bash
flutter pub get
flutter run
```

بوابة الجودة:

```bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
flutter build apk --debug
```

لا تحتاج نسخة التطوير إلى مفتاح توقيع. لإنتاج نسخة Android رسمية موقعة، أنشئ `android/key.properties` وملف keystore محليًا؛ كلاهما مستبعد من Git ولا ينبغي مشاركتهما.

## بنية المشروع

- `lib/app`: هيكل التطبيق والتنقل.
- `lib/core`: قاعدة البيانات، الأمان، الثيم وأدوات الأموال.
- `lib/features`: الحسابات، الحركات، الديون، الميزانيات والتقارير.
- `test`: اختبارات قاعدة البيانات وقواعد العمل والواجهة.
- `md`: وثائق المنتج والسكيمة والأمان والإصدارات.
